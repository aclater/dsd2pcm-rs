# C interface

`crates/dsd2pcm-capi` builds `libdsd2pcm.so` (`.dylib`, `.dll`) and `libdsd2pcm.a` with
`cargo build --release -p dsd2pcm-capi`. The header is
`crates/dsd2pcm-capi/include/dsd2pcm.h`, generated by cbindgen from the crate (see
`cbindgen.toml`); its comments document every item. Static linking on Linux also needs
`-lpthread -ldl -lm`; `cargo rustc --release -p dsd2pcm-capi --lib --crate-type staticlib
-- --print native-static-libs` prints the list for other platforms.

## Rules

- Every function that can fail returns an `int` status: `DSD2PCM_OK` (0) or a
  `DSD2PCM_E_*` code. `dsd2pcm_last_error()` gives the message of the last failure on the
  calling thread (owned by the library, valid until the next failure on that thread);
  `dsd2pcm_status_str()` names a code.
- Every pointer is checked for NULL (`DSD2PCM_E_NULL`). A buffer always comes with its
  length; a NULL buffer is allowed only with length 0 where the function says so.
- Output buffers must not overlap each other or any input; the library checks and returns
  `DSD2PCM_E_INVALID_ARGUMENT`. On any error nothing is written to the outputs.
- No panic crosses the interface: each entry point catches it and returns
  `DSD2PCM_E_INTERNAL`.
- The only memory the caller frees is a converter, with `dsd2pcm_frames_free`. Strings
  returned by the library are static or owned by it.
- Paths are NUL-terminated UTF-8 on every platform, Windows included (`DSD2PCM_E_INVALID_ARGUMENT`
  if not valid UTF-8).
- Settings structs are zero-initialised defaults apart from the rate (and channel count):
  cutoff `DSD2PCM_CUTOFF_STANDARD`, filter `DSD2PCM_FILTER_DEFAULT`, 0 dB, all cores, no
  callback. Integer selectors (cutoff, filter, format, threads) are checked, never trusted.
- `filter` selects the filter and quantiser: 0 is the default (scarletbook-pcm 0.7.0's
  samples). `DSD2PCM_FILTER_PYSACD` (1) is reserved for the pysacd preset and returns
  `DSD2PCM_E_UNSUPPORTED` in this version. `dsd2pcm_run.first_frame`, the run's frame index
  in its area, is the preset's dither seed; the default filter ignores it.

## Whole files

```c
int dsd2pcm_convert_file(const char *input_path, const char *output_path,
                         const dsd2pcm_file_options *options,
                         dsd2pcm_file_report *report /* may be NULL */);
```

Converts a DSF or DFF file (DSD64) to a 24-bit WAV file. `options` holds the rate (88200,
176400, 352800), cutoff, filter, gain (-120 to +24 dB), `threads` (0: all cores, 1: the
calling thread only) and an optional progress callback:

```c
typedef int (*dsd2pcm_progress_fn)(uint64_t done, uint64_t total, void *user_data);
```

It is called on the calling thread, once before the first block and after each block, with
the output samples per channel done and in all; a non-zero return stops the conversion with
`DSD2PCM_E_CANCELLED`. It must not unwind (C++ exceptions, `longjmp`) into the library.
After an error the output file may exist and be incomplete.

`crates/dsd2pcm-capi/tests/c/convert.c` is a complete program:

```c
static int progress(uint64_t done, uint64_t total, void *user_data) {
    (void)user_data;
    fprintf(stderr, "\r%3d%%", total ? (int)(100 * done / total) : 100);
    return 0; /* any other value cancels */
}

dsd2pcm_file_options opts = {.rate_hz = 176400, .progress = progress};
dsd2pcm_file_report report;
int rc = dsd2pcm_convert_file(argv[1], argv[2], &opts, &report);
if (rc != DSD2PCM_OK)
    fprintf(stderr, "dsd2pcm: %s: %s\n", dsd2pcm_status_str(rc), dsd2pcm_last_error());
```

## Frame runs

The C counterpart of `dsd2pcm::frames::Converter`: Super Audio CD frames (`channels x 4704`
bytes, channels interleaved byte by byte, earliest sample in the most significant bit) to
interleaved 24-bit PCM, a run at a time, with the frames before and after the run as
context. Any run with its neighbours gives the bytes of that run in a whole-area
conversion, and those equal `dsd2pcm_convert_file`'s.

```c
dsd2pcm_frames_config cfg = {.rate_hz = 176400, .channels = 2};
dsd2pcm_frames *conv;
if (dsd2pcm_frames_new(&cfg, &conv) != DSD2PCM_OK) { /* dsd2pcm_last_error() */ }

dsd2pcm_run run = {
    .before = prev, .before_len = frame_bytes,   /* NULL, 0 at the start of the area */
    .frames = data, .frames_len = n * frame_bytes,
    .after = next,  .after_len = frame_bytes,    /* NULL, 0 at the end of the area */
    .first_frame = index_of_first_frame,
};
size_t out_bytes = dsd2pcm_frames_output_bytes(conv, n, DSD2PCM_FORMAT_S24LE);
int rc = dsd2pcm_frames_convert(conv, &run, DSD2PCM_FORMAT_S24LE, pcm, out_bytes,
                                frame_clipped, n /* or NULL, 0 */, &stats /* or NULL */);
dsd2pcm_frames_free(conv);
```

- Frames in separate buffers: set `frame_ptrs` (an array of `frame_count` pointers, one
  frame each) instead of `frames`/`frames_len`. Setting both is an error.
- `DSD2PCM_FORMAT_S24LE`: 3-byte little-endian samples, ready for a WAV or FLAC writer.
  `DSD2PCM_FORMAT_I32`: sign-extended `int32_t`; `out` must be 4-byte aligned.
- `dsd2pcm_frames_frame_bytes`, `_samples_per_frame` (1176, 2352 or 4704),
  `_context_bytes` (the neighbour bytes the output depends on) and `_output_bytes` size the
  buffers; each returns 0 for a NULL handle.
- `frame_clipped` receives the clamped samples per frame (all channels); `stats` the
  clamped samples per channel and their sum.
- After the first call a converter allocates nothing. Use one converter per thread: a call
  while another thread uses the same handle returns `DSD2PCM_E_BUSY`. Freeing a handle
  while another thread uses it is undefined.

`crates/dsd2pcm-capi/tests/c/minimal.c` is the smallest complete program (see the README for
the commands), and `tests/c/smoke.c` uses every function.

## Checks

`crates/dsd2pcm-capi/check.sh`, from the repository root, checks that the committed header
equals cbindgen's output (cbindgen from `PATH`, or the binary named by the `CBINDGEN`
environment variable; install it with `cargo install cbindgen`), then builds and runs the C programs under gcc and clang with
`-Wall -Wextra -Werror`, and the smoke test under clang's AddressSanitizer and
UndefinedBehaviorSanitizer (`ASAN=0` skips that). The Rust tests of the interface
(`cargo test -p dsd2pcm-capi`) cover NULL pointers, bad lengths and values, overlapping
buffers, cancelling, busy and poisoned handles, allocation after warm-up, and byte identity
with the Rust API.
